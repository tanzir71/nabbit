- Kept `com.nabbit.app` from the handoff despite Tauri warning that `.app` suffix is not recommended on macOS; this should change before release if an organization-owned bundle ID is available.
- Treat corrupt or quarantined downloader binaries as repairable: engine status now marks a binary unhealthy if its version probe fails, and Repair re-fetches yt-dlp plus copies ffmpeg from `PATH` when available.
- The release updater endpoint currently targets `https://github.com/tanzir/nabbit/releases/latest/download/latest.json`; change it if the production repository differs.
- `NABBIT_APP_DATA_DIR` can override the app-data directory for disposable acceptance tests; normal launches use the OS app-data path.
- `NABBIT_ACCEPTANCE_COMMAND_DIR` enables a test-only local command directory for packaged-app smoke automation; normal launches do nothing unless the env var is set.
- `NABBIT_ACCEPTANCE_FAKE_DOWNLOAD` swaps external yt-dlp execution for a deterministic app-managed fake runner, used only by packaged-app acceptance smoke for progress/cancel/retry/concurrency/history checks.
- `NABBIT_ACCEPTANCE_DOWNLOAD_SECTION` is used by the opt-in real media smoke to pass yt-dlp `--download-sections` while still exercising the real app download path.
