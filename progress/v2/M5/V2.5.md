# V2.5 — Compact, Peek, Expanded shell, Drop and motion

The production island uses the V0-selected hybrid renderer: idle and live content are native DirectComposition/Direct2D, with no collapsed WebView2. Peek, Expanded and Drop create a transparent, nonactivating 720×460 reference WebView. The native compact scene stays visible until a matching generation acknowledges the web paint. Collapse returns ownership to the native renderer and destroys the WebView. Stale paint acknowledgements and old HWND destruction callbacks cannot destroy a newer view. Configuration changes reposition the fixed host; animation never resizes either HWND.

Compact rendering covers link review, download/tool progress, media, timer, privacy, power, download completion/error, note/link saved, moved files, tool result and volume, with a secondary bubble. Original Figma SVGs are shared by the web and native renderers. The 99 unchanged SVG exports, intrinsic sizes and SHA-256 hashes are pinned in `src/assets/island/manifest.json`; semantic slots retain their source node groups. Native text uses the existing bundled private Geist/Geist Mono collection. Dynamic progress, percentages, ellipsis, artwork and text are rendered from typed activity values. Native artwork accepts only bounded local PNG data URIs. Volume activity expires after 1.5 seconds even while hidden; the CoreAudio producer remains a later service task.

Expanded has the six shared tabs, active label, Search, full-app and Settings actions, a lazy module body and a 420px height limit. Per-label tab, search, filters, URL draft and per-tab scroll survive WebView destruction/recreation. Scroll restoration waits for lazy content; pointer scrolling cancels the restore. Clipboard reads the existing SQLite service and reacts to its events. Nab reviews an explicit URL and queues a download only after its button is clicked. Settings opens the existing tray Settings component through a consumed navigation intent. The full redesigned Nab module, notes/Tack, shelf/pins/tools, media/timer services and keyboard bindings remain their named V3–V6 tasks. Empty modules show real empty states; mock content is confined to screenshot fixtures.

Drop classifies URL/text/files, orders its three zones, preserves an explicit zone through the native file callback and stages the payload for the receiving module. Download-zone URLs enter review. Notes/Files intake drafts are held in the island session and shown in the receiving tab; this task does not claim persistent notes, shelf storage or tool execution. Files use WebView2 AdditionalObjects to resolve actual disk paths, validated natively. A virtual file with no disk path gets an unsupported receipt. Dropping never starts a download or moves an input file.

CSS `linear()` curves are generated at build time from §4.6 springs, with no animation library. Native compact geometry uses matching sampled curves and interrupted geometry. A newly allocated WebView seeds its opening geometry from the native compact dimensions, preserving square notch top corners. Web motion includes the 60ms/120ms live-content fade, 320ms Peek, 380ms Expanded, 20ms tab stagger, inert 80ms outgoing-content snapshot before 220ms collapse, one 400ms alert scale and 200ms maximised fade. Reduced motion uses a 120ms content crossfade and instant geometry. Exit snapshots are removed by animation completion, with no JS animation loop or idle timer. The existing native worker retains click-through until the end of the maximised fade. Hidden/forced suppression takes precedence.
