SYS · 02

Build it with the engine you control.

Ask your coding agent

Start with the privacy contract and never bundle downloader binaries from an unverified source.

Read https://tanzir71.github.io/nabbit/llms.txt and https://github.com/tanzir71/nabbit. Build the Windows Tauri release, fetch yt-dlp with the provided script, supply ffmpeg, run npm verify plus Cargo tests/clippy, then run the isolated acceptance smoke. Do not touch the user’s real clipboard database.

Manual path

npm install npm run verify cargo test --manifest-path src-tauri/Cargo.toml ./scripts/fetch-binaries.ps1 npm run tauri:dev

SYS · 05

Before you install.

Does copying a link start a download?

Never. It only stages the link. A user must click Download.

Where is clipboard history stored?

In local SQLite under the OS app-data directory, with retention you choose.

Does this public demo use my clipboard?

No. It is a deterministic HTML simulation and has no clipboard or network access.

Is the Nabbit name release-clear?

No. It is a working codename and needs product/legal review before public release.
