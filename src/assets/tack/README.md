# Tack connection assets

Unmodified SVG exports from Nabbit Figma file `tBm7NNhh1Y9aTQPJ3WxY5v`, nodes `19:5` and `19:102`, fetched for V4.4. `manifest.json` records intrinsic dimensions and source hashes. The on/off toggle exports are byte-identical to the existing shared Toggle assets, which are reused. No temporary asset URL is used at runtime.

The original radio exports retain their 14px dimensions; dark mode inverts their colours without changing the files. Existing DesignIcon and Toggle components supply the other theme-aware exports at their original sizes. The app uses real membership names/roles and omits illustrative card counts and registration status that the API does not provide.
